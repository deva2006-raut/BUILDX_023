# MEDNEXUS 360 — Frontend

React + Vite frontend for the MEDNEXUS 360 emergency response coordination platform.

## Stack

- React 19 + Vite
- Tailwind CSS
- Leaflet (live maps)
- Lucide icons
- Oxlint

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build

```bash
npm run build
npm run preview
```

The backend must be running on port **4001** — see the [root README](../README.md).
